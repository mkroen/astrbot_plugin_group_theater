# 群友四格小剧场

从群聊中挑选有趣片段，生成多个四格小剧场候选，选一个 ID 即可出图。支持以群友头像作为人物参考。

## 安装

适用于 **AstrBot ≥ 4.28.0**，支持 **OneBot / NapCat 群聊**。

在插件管理中通过仓库地址安装：

```text
https://github.com/mkroen/astrbot_plugin_group_theater
```

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用小剧场 | 打开后使用 |
| 群白名单 | 默认留空，所有群可用；填写后仅允许指定群 |
| 分析 / 编剧模型 | 留空跟随 AstrBot 当前会话模型，也可从已配置的模型列表中选择 |
| 绘图协议 | 选择 `gemini`、`openai_chat` 或 `openai_images` |
| API基础地址、密钥、绘图模型ID | 填写绘图服务的信息 |

绘图密钥也可通过“复用 AstrBot 提供商凭据ID”读取；使用这种方式时，独立密钥留空，地址留空则一并复用。

`gemini` 对应 Gemini 原生接口，`openai_chat` 对应支持图片输出的 Chat 接口，`openai_images` 对应 Images 兼容接口。使用头像参考时，绘图入口需要支持图片输入；Images 入口需支持 `edits`。

候选数量、画风和头像参考可在配置中调整。

## 使用

命令需由 **AstrBot 管理员**在群中使用。

**1. 取材**

```text
/小剧场 取材
```

默认读取近期最多 120 条消息，准备 3 个候选，以合并转发聊天记录展示。每个候选都包含 **ID、人物和完整四格分镜**。可指定条数，例如 `/小剧场 取材 80`；素材不足时可能少给候选。

分析和编剧使用文字模型，此时不会绘图。

**2. 选 ID 出图**

```text
/小剧场 出图 <ID>
```

替换为候选中的实际 ID，直接用已准备好的分镜生成漫画。成功后重复发送同一命令，只会重发已有图片。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/小剧场` | 查看基础帮助 |
| `/小剧场 取材 [条数]` | 生成候选 |
| `/小剧场 分镜 <ID>` | 查看候选 |
| `/小剧场 出图 <ID>` | 生成漫画或重发已有图片 |

## 说明

- 候选只能由创建人在原群使用，默认 **24 小时过期**，下次操作时清理。
- 取材会将文字和昵称发送给文字模型，出图会将分镜及启用的头像发送给绘图服务；不持续监听群聊或识别群消息图片。
